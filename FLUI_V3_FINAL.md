## 🚀 COMO USAR O FLUI v3.0

```bash
# Build
npm run build

# Executar
npm start

# Primeiros passos
> /settings               # Configurar API Key
> /test                   # Testar conexão
> /models                 # Selecionar modelo
> /theme                  # Escolher tema (opcional)

# Usar tools automaticamente
> Crie um arquivo chamado teste.txt com "Hello Flui"
[LLM usa tool createFile automaticamente]

> Busque por "Flui" nos arquivos
[LLM usa tool searchInFiles]

# Usar agentes
> @CodeAssistant crie uma API REST completa
[Resposta especializada]

# Executar automações
> /automations
[Enter para executar ou criar nova]

# Gerenciar sessions
> /sessions
[Alternar entre sessions ou excluir]

# Ver comandos
> /help
```
