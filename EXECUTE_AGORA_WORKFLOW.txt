🧪 TESTE COMPLETO:
═══════════════════════════════════════════════════════════

1. Home → Clicar "Nova Automação"

2. Digitar nome: "Meu Workflow"

3. Clicar "Adicionar Nó"
   → Modal abre
   → Ver agentes, MCPs, tools

4. Selecionar "Assistente Geral"
   → Nó azul aparece
   → Modal fecha

5. Clicar no nó
   → Modal configuração abre
   → Preencher prompt
   → Salvar

6. Adicionar mais nós:
   → Webhook (amarelo)
   → HTTP Request (cyan)

7. Conectar nós:
   → Arrastar handle direito → esquerdo
   → Linha roxa animada

8. Clicar "Salvar"
   → Volta para home
   → Automação na lista
