## 🚀 COMO USAR

### Iniciar Sistema:
```bash
# Terminal 1: API
npm run start:api

# Terminal 2: Frontend
cd flui-frontend-vite && npm run dev
```

### Acessar:
- **Frontend:** http://localhost:5173
- **API:** http://localhost:3001

### Criar Automação:
1. Nova Automação
2. Adicionar nodes (auto-conectam)
3. Configurar (clicar 🔗 para selecionar outputs)
4. Salvar
5. Executar
6. Ver logs!
