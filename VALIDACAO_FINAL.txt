Via API:
curl -X POST http://localhost:3001/api/tools/condition-flex/execute \
  -H "Content-Type: application/json" \
  -d '{
    "value": "comprar produto",
    "paths": ["comprar", "vender", "ajuda"],
    "matchType": "contains"
  }'

Resultado Esperado:
{
  "success": true,
  "result": {
    "matchedPath": "comprar",
    "matched": true,
    "value": "comprar produto"
  }
}

Via Workflow:
  1. Adicione node "Condition Flex"
  2. Configure paths: ["comprar", "vender", "ajuda"]
  3. Conecte 3 nodes diferentes para cada path
  4. Execute workflow
  5. Veja roteamento automático
