# Flui Frontend - Workflow Visual Studio

## 🚀 Instalação

### Termux/Android:
```bash
npm install --legacy-peer-deps --no-optional
```

### Outros sistemas:
```bash
npm install
```

## 🎯 Executar

```bash
npm run dev
```

Acesse: http://localhost:8080

## 🔧 Troubleshooting

### Erro SWC no Termux:
O projeto já está configurado para usar Babel como fallback.

Se ainda houver problemas:
```bash
rm -rf node_modules .next
npm install --legacy-peer-deps --no-optional
```

## 📦 Tecnologias

- Next.js 14.2 (com Babel fallback)
- TypeScript
- Tailwind CSS
- React Flow (workflow visual)
- Lucide Icons
- Axios

## 🎨 Features

- Dashboard com estatísticas
- Editor visual de workflows
- Drag-and-drop de nós
- Configuração interativa
- Design responsivo
- Dark mode elegante
